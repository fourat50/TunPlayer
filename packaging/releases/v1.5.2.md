# TunPlayer 1.5.2 — Fenêtre de recherche de sous-titres

- Correction de l’icône manquante qui empêchait l’ouverture de la fenêtre de résultats après un clic sur « Rechercher en ligne ».
- Recherche automatique dès l’ouverture, avec le contenu en cours et la langue préférée.
- Résultats sélectionnables pour télécharger et activer un sous-titre sans relancer la vidéo.
- Les filtres, le test de connexion SubDL et les autres sources sont conservés.

## Installation Linux autonome

Fermez TunPlayer, puis installez :

```bash
sudo apt install ./tunplayer_1.5.2+standalone1_amd64.deb
```

Python, GTK, mpv et FFmpeg sont inclus. Votre profil et vos clés sont conservés.
Cible : Ubuntu 24.04 / Linux Mint 22, x86_64, glibc >= 2.39, X11 / XWayland.
L’archive portable se lance avec `./AppRun`, sans sudo.

314 tests automatisés réussis. L’erreur d’icône est reproduite avant correction puis résolue.
Les SVG sont réellement décodés et les boutons utilisent ces ressources dans les tests.
Deux parcours complets, film et épisode, vérifient l’ouverture depuis le dialogue audio,
la recherche automatique, la liste, la sélection, le téléchargement ZIP et l’activation dans le vrai mpv.
Les réponses HTTPS et les widgets d’affichage sont simulés ; le bureau graphique et les recherches réseau réelles restent à valider sur la machine de l’utilisateur.
