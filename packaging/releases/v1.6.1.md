# TunPlayer 1.6.1 — Linux : démarrage et fluidité du lecteur

Le diagnostic sur le bureau utilisateur a mesuré 0,83 s pour un film, 3,49 s pour un direct
et 2,78 s pour un épisode. Les étapes d’interface et d’envoi au lecteur étaient rapides,
mais une interrogation périodique du lecteur a bloqué la boucle GTK pendant 364 ms.

- Suivi de la position, durée, pause et du tampon par événements mpv ; suppression des lectures synchrones répétées de ces propriétés dans la boucle d’interface.
- Analyse initiale plus courte pour les directs HTTP(S). Les films, épisodes, radios et réessais conservent l’analyse habituelle.
- Vérification des abonnements séparée de l’import : les contenus deviennent disponibles sans attendre une API de compte lente.
- Infobulles de catégories corrigées pour les noms contenant une esperluette.
  Le retour GTK à six valeurs est vérifié à partir du typelib installé.

359 tests automatisés réussis. Les tests utilisent le vrai moteur mpv, vérifient
que la boucle de lecture n’appelle plus les getters synchrones et comparent deux
démarrages MPEG-TS avec entrée locale à débit contrôlé, en conservant audio et vidéo.
Les délais sur les services réels dépendent aussi du réseau et du fournisseur.

Fermez TunPlayer et installez :

```bash
sudo apt install ./tunplayer_1.6.1+standalone1_amd64.deb
```

Profil, favoris, historique et clés conservés. Python, GTK, mpv et FFmpeg inclus.
Cible : Ubuntu 24.04 / Linux Mint 22, x86_64, glibc >= 2.39, X11 / XWayland.
