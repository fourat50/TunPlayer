# TunPlayer 1.1.0 — Radio et Linux autonome

La rubrique **Radio** rejoint **Votre espace**. Elle utilise l’annuaire
public Radio Browser, la meme API qu’[OpenRadio](https://github.com/raj-khan/openradio).
Aucun compte ni cle API n’est necessaire.

- Filtres par pays et categorie, recherche par nom et tri par popularite / nom / pays.
- Logos, codec et debit, pages de 40 stations et favoris locaux **Mes radios**.
- Requetes en arriere-plan, miroirs HTTPS et cache des resultats deja visites.
- Lecteur audio integre, commandes visibles, stations precedente / suivante.
- Retour et Stop coupent la lecture et reviennent a Radio ; la navigation dans l’annuaire peut continuer pendant l’ecoute.

Les fonctions television, films et series sont conservees. Votre bibliotheque
et vos sources restent dans votre profil local.

## Installation ou mise a jour

Telechargez `tunplayer_1.1.0+standalone1_amd64.deb`, fermez TunPlayer puis lancez :

```bash
sudo apt install ./tunplayer_1.1.0+standalone1_amd64.deb
```

Le programme apparait dans le menu des applications, ou se lance avec `tunplayer`.
Le paquet remplace les anciennes versions sans supprimer le profil.
Python 3.12, GTK 3, PyGObject, Cairo, mpv et FFmpeg sont inclus.
Environ 132 Mo a telecharger et 344 Mo installes.

L’archive `TunPlayer-1.1.0-linux-x86_64-standalone.tar.gz` peut aussi etre
extraite dans un dossier de votre choix : lancez `./AppRun`, sans sudo.
Les notices tierces et les versions des composants sont incluses.

## Compatibilite et verification

Cible initiale : **Ubuntu 24.04 / Linux Mint 22, x86_64, glibc >= 2.39**.
Le serveur X11 / XWayland et les pilotes materiels restent fournis par Linux.
L’ecoute des stations necessite une connexion Internet ; aucune playlist IPTV
ni aucun abonnement n’est fourni.

Telechargez `Standalone-SHA256SUMS` avec les deux fichiers, puis verifiez :

```bash
sha256sum --check Standalone-SHA256SUMS
```

183 tests automatises reussis, dont les filtres et pannes de l’annuaire avec
reponses simulees, ainsi que la lecture audio et le retour a la video sur le
vrai moteur mpv. Le runtime prive, la resolution de 319 fichiers ELF, la
relocation, les certificats, les SVG, FFmpeg et l’installation / suppression
isolees sont verifies. La mise a jour reelle de 1.0.0 vers 1.1.0 a ete
confirmee sous Linux Mint. L’acces reel aux stations, le rendu graphique
complet et les autres distributions restent a valider depuis le bureau.

Le tag `v1.1.0` designe le commit utilise pour construire les paquets ; les
outils de publication peuvent recevoir des mises a jour ulterieures sur `main`.
