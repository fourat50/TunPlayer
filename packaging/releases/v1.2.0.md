# TunPlayer 1.2.0 — Téléchargements et transitions du lecteur

- Films : bouton **Télécharger** dans la fiche.
- Épisodes : icône de téléchargement dans chaque ligne.
- Saisons : sélectionnez une saison puis **Télécharger la saison** pour ajouter tous ses épisodes.
- Rubrique **Téléchargements** : dossier, progression, pause / reprise, annulation et lecture locale dans TunPlayer.
- File séquentielle, historique privé et fichiers partiels séparés des fichiers terminés.
- Reprise HTTP validée lorsque le serveur fournit un ETag fort ; sinon, reprise depuis le début.
- HLS / DASH téléchargés en Matroska avec FFmpeg ; reprise depuis le début pour ces flux.
- Vues exclusives pour le catalogue, la vidéo et la radio, sans superposition de fenêtres natives.
- Démarrage après la mise en place de la zone vidéo, annulation des sélections dépassées et menu latéral défilant.

## Mise à jour Linux autonome

Fermez TunPlayer, puis installez :

```bash
sudo apt install ./tunplayer_1.2.0+standalone1_amd64.deb
```

Python, GTK, mpv et FFmpeg sont inclus. Votre profil est conservé.
Cible : Ubuntu 24.04 / Linux Mint 22, x86_64, glibc >= 2.39, affichage X11 / XWayland.
Les pilotes matériels restent fournis par le système.

L’archive portable peut être extraite puis lancée avec `./AppRun`, sans sudo.
Vérifiez les deux fichiers avec `sha256sum --check Standalone-SHA256SUMS`.

212 tests automatisés réussis. Les téléchargements, les plages de reprise, l’absence d’écrasement, les saisons
complètes et les lancements différés sont couverts par des tests automatisés.
La conversion d’une playlist HLS locale est vérifiée avec le vrai FFmpeg.
Les fournisseurs réels et les transitions graphiques complètes restent à
valider depuis une session de bureau disposant du réseau.
