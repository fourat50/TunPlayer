# TunPlayer 1.3.1 — Démarrage du lecteur intégré

- Attente de l’affichage du lecteur et d’une taille stable avant le chargement vidéo.
- Chargement suspendu si la fenêtre est masquée ou si le catalogue a été rouvert pendant le démarrage.
- Surface native réservée à mpv, sans double tampon GTK ; synchronisation X11 avant l’intégration du lecteur.
- Conservation des catégories protégées par PIN, des téléchargements et des commandes de la version 1.3.0.

## Installation Linux autonome

Fermez TunPlayer, puis installez :

```bash
sudo apt install ./tunplayer_1.3.1+standalone1_amd64.deb
```

Python, GTK, mpv et FFmpeg sont inclus. Votre profil est conservé.
Cible : Ubuntu 24.04 / Linux Mint 22, x86_64, glibc >= 2.39, X11 / XWayland.
L’archive portable se lance avec `./AppRun`, sans sudo.

239 tests automatisés réussis. Les cas fenêtre masquée, navigation pendant le démarrage,
redimensionnement initial et annulation des anciens démarrages sont couverts.
Le défaut visuel signalé ne peut pas être reproduit sans accès au bureau graphique ;
son absence après correction reste à confirmer sur la machine de l’utilisateur.
