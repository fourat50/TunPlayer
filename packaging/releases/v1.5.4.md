# TunPlayer 1.5.4 — Correction des liens SubDL

Le diagnostic réel a identifié pourquoi le compte était connecté mais la liste restait vide :
SubDL renvoyait 64 fichiers pour Inception et 10 pour le contenu récent du profil,
tous rejetés parce que leur lien contenait `?api_key=…`.

Les liens de ce format sont désormais acceptés sur le serveur SubDL vérifié.
La clé est retirée de l’adresse conservée ; le téléchargement utilise votre clé
personnelle par en-tête, supprimé lors d’une redirection.

Validation réelle avec le compte utilisateur après correction : 64 fichiers reçus et
64 retenus pour Inception, 10 reçus et 10 retenus pour le contenu récent ; un sous-titre
témoin téléchargé et validé. Les tests automatisés rejouent également des extraits
expurgés des réponses réelles et utilisent un transport HTTPS simulé pour les autres cas.
Le diagnostic reste disponible avec `scripts/diagnose_subtitles.py --download`.

340 tests automatisés réussis, dont les parcours film / épisode avec activation
du sous-titre dans le vrai moteur mpv.

Fermez TunPlayer, puis installez :

```bash
sudo apt install ./tunplayer_1.5.4+standalone1_amd64.deb
```

Python, GTK, mpv et FFmpeg sont inclus. Le profil et les clés sont conservés.
Cible : Ubuntu 24.04 / Linux Mint 22, x86_64, glibc >= 2.39, X11 / XWayland.
