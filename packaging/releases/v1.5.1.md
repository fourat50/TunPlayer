# TunPlayer 1.5.1 — Recherche de sous-titres et test SubDL

- SubDL est activé au retour de la configuration lorsque sa clé vient d’être ajoutée, sans rouvrir la recherche.
- Les résultats et erreurs s’affichent source par source, avec progression et bouton Annuler ; une source lente ne masque plus les autres résultats.
- **Préférences → Sous-titres en ligne → Configurer les sources → Tester la connexion SubDL**.
- Test sur le compte authentifié, avec quotas restants lorsqu’ils sont disponibles et enregistrement de la configuration après réussite.
- Erreurs d’authentification, DNS, délai de réponse et TLS explicites ; un test échoué ne valide pas la clé.
- Les résultats d’une ancienne recherche ou d’un test sur une clé modifiée sont ignorés.

## Installation Linux autonome

Fermez TunPlayer, puis installez :

```bash
sudo apt install ./tunplayer_1.5.1+standalone1_amd64.deb
```

Python, GTK, mpv et FFmpeg sont inclus. Votre profil et vos clés enregistrées sont conservés.
Cible : Ubuntu 24.04 / Linux Mint 22, x86_64, glibc >= 2.39, X11 / XWayland.
L’archive portable se lance avec `./AppRun`, sans sudo.

308 tests automatisés réussis : API, contrôleur, clics sur les boutons avec widgets simulés,
résultats progressifs, annulations, test du compte, quotas épuisés et erreurs réseau.
Le bureau graphique n’est pas accessible dans l’environnement de validation.
L’essai direct avec la clé présente dans le profil a échoué en raison de l’accès réseau indisponible ;
la validité du compte réel n’est donc pas revendiquée. Le bouton permet d’effectuer ce contrôle depuis le bureau connecté.
