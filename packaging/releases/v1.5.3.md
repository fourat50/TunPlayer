# TunPlayer 1.5.3 — Résultats de recherche SubDL

- Recherche SubDL via l’API v2 authentifiée, comme le test de connexion.
- Reconnaissance des langues sous forme de code ou de nom et des numéros d’épisode dans le nom des fichiers.
- Affichage des résultats individuels incomplets avec avertissement de vérification manuelle, sans proposer les épisodes explicitement différents ni les packs non détaillés.
- Option **Toutes les langues** pour élargir une recherche vide.
- Compteurs SubDL des fichiers reçus et retenus, avec raisons de filtrage lorsqu’aucun résultat n’est affiché.
- Nettoyage des titres IPTV et nouvel essai sans année pour une recherche de film vide.
- Téléchargement par identifiant API lorsqu’aucun lien public n’est fourni.

## Installation Linux autonome

Fermez TunPlayer, puis installez :

```bash
sudo apt install ./tunplayer_1.5.3+standalone1_amd64.deb
```

Python, GTK, mpv et FFmpeg sont inclus. Votre profil et vos clés sont conservés.
Cible : Ubuntu 24.04 / Linux Mint 22, x86_64, glibc >= 2.39, X11 / XWayland.
L’archive portable se lance avec `./AppRun`, sans sudo.

330 tests automatisés réussis. Les réponses sans `status`, langues nommées, numéros manquants,
packs détaillés, recherche multilingue et compteurs sont couverts. Les parcours film / épisode
traversent les adaptateurs v2 et activent les sous-titres dans le vrai mpv.
Les réponses HTTPS et les widgets d’affichage sont simulés ; les recherches sur le service réel restent
à vérifier depuis un bureau connecté, l’accès DNS étant indisponible dans l’environnement de construction.
