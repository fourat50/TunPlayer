# TunPlayer 1.5.0 — Sous-titres SubDL

- SubDL rejoint OpenSubtitles.com et Podnapisi dans la recherche du lecteur.
- Ajoutez votre clé personnelle dans **Préférences → Sous-titres en ligne → Configurer les sources → Clé API SubDL**.
- Clé disponible sur https://subdl.com/panel/api ; elle est distincte de la clé OpenSubtitles.
- Recherche de films et d’épisodes, langues et variantes prises en charge par le fournisseur.
- Sélection du fichier individuel d’un pack de saison lorsque les métadonnées désignent l’épisode demandé.
- Téléchargement et activation dans la lecture en cours, avec conservation du sous-titre et du décalage.
- Clés enregistrées dans le profil privé, aucune clé incluse dans le paquet ni envoyée au serveur de fichiers.

## Installation Linux autonome

Fermez TunPlayer, puis installez :

```bash
sudo apt install ./tunplayer_1.5.0+standalone1_amd64.deb
```

Python, GTK, mpv et FFmpeg sont inclus. Votre profil est conservé.
Cible : Ubuntu 24.04 / Linux Mint 22, x86_64, glibc >= 2.39, X11 / XWayland.
L’archive portable se lance avec `./AppRun`, sans sudo.

291 tests automatisés réussis, dont 14 tests SubDL couvrant les requêtes, les langues,
les packs de saisons, les liens de téléchargement et la séparation des clés API.
Les réponses réseau sont contrôlées dans les tests. La recherche sur les services réels,
les quotas des comptes et le rendu graphique restent à valider depuis un bureau connecté.
