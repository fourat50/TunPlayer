TunPlayer 1.0.0 pour Linux
=========================

Lecteur de bureau en francais : television en direct, films et series,
sources M3U / Xtream, guide XMLTV, favoris et reprise de lecture.

- Video mpv integree dans l'application, pistes audio et sous-titres.
- Categories et episodes accessibles pendant la lecture.
- Commandes Precedent / Suivant avec les noms des contenus.
- Panneau ajustable, choix de reprise et reconnexion automatique.
- Enregistrement manuel avec FFmpeg.

Installation
------------

Telechargez `tunplayer_1.0.0_all.deb`, ouvrez un terminal dans son dossier :

```bash
sudo apt install ./tunplayer_1.0.0_all.deb
```

Lancez ensuite **TunPlayer** depuis le menu des applications ou avec
`tunplayer`. Aucune playlist ni abonnement n'est inclus.

Ce paquet vise Debian, Ubuntu et Linux Mint disposant de Python >= 3.10
et des dependances declarees. Construit et verifie sur Linux Mint 22.3
(base Ubuntu 24.04). Sous Wayland, XWayland doit etre disponible.

Verification du telechargement
-----------------------------

Telechargez aussi `SHA256SUMS`, puis executez dans le meme dossier :

```bash
sha256sum --check SHA256SUMS
```

Le programme provient du tag `v1.0.0` ; les outils de construction et
de verification du paquet sont disponibles dans le depot sur `main`.
Le paquet a ete verifie par extraction, lancement `--help` et installation /
desinstallation dans une racine temporaire. La lecture graphique complete
et les autres distributions n'ont pas ete validees dans cet environnement.
