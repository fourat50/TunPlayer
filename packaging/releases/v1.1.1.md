# TunPlayer 1.1.1 — Filtres et compteurs Radio

Cette mise a jour corrige un compteur trompeur dans le menu des genres du
lecteur radio : le total mondial annonce par l’annuaire ne correspondait
pas aux stations du pays et de la recherche selectionnes.

- Retrait des totaux mondiaux de genres dans le lecteur Radio.
- Rappel du pays, du genre, de la recherche et du filtre Mes radios.
- Nombre de stations affiche explicitement pour la page courante (40 au maximum).
- Messages de liste vide adaptes a la pagination et actions pour elargir
  la recherche a tous les pays ou a tous les genres sans perdre les autres filtres.

« Indie » est un genre musical, distinct du pays « Inde ».
L’annuaire peut repertorier de nombreuses stations d’un genre dans le monde
et ne retourner aucun resultat pour sa combinaison avec un pays particulier.

## Installation

Fermez TunPlayer, telechargez le paquet autonome puis executez :

```bash
sudo apt install ./tunplayer_1.1.1+standalone1_amd64.deb
```

Cible : Ubuntu 24.04 / Linux Mint 22, x86_64, glibc >= 2.39.
Python, GTK, mpv et FFmpeg sont inclus. Votre profil et vos favoris sont conserves.
L’archive portable peut etre extraite puis lancee avec `./AppRun` sans sudo.
Les empreintes des deux fichiers sont fournies dans `Standalone-SHA256SUMS`.

190 tests automatises reussis. Le rendu graphique et les stations Internet
doivent etre verifies dans une session de bureau disposant du reseau.
