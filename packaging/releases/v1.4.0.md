# TunPlayer 1.4.0 — Sous-titres en ligne

- Dans le lecteur : **Audio et sous-titres → Rechercher en ligne**.
- Recherche par titre, année, saison, épisode et langue ; 189 langues et variantes sélectionnables, selon les disponibilités des sources.
- Sources intégrées : Podnapisi sans compte et OpenSubtitles.com avec votre propre clé API. Connexion OpenSubtitles facultative pour utiliser le quota du compte.
- Recherche en arrière-plan, résultats triés selon une correspondance estimée et erreurs indépendantes pour chaque source.
- Téléchargement et activation sans relancer la vidéo ; sous-titre et décalage conservés pour la prochaine lecture.
- Validation des fichiers et archives, protection contre les anciens résultats après changement de contenu et respect des catégories protégées par PIN.
- Adaptateur Subliminal 2.8 facultatif ; cette distribution contient les deux sources intégrées, sans les dépendances de l’extension.

## Installation Linux autonome

Fermez TunPlayer, puis installez :

```bash
sudo apt install ./tunplayer_1.4.0+standalone1_amd64.deb
```

Python, GTK, mpv et FFmpeg sont inclus. Votre profil est conservé.
Cible : Ubuntu 24.04 / Linux Mint 22, x86_64, glibc >= 2.39, X11 / XWayland.
L’archive portable se lance avec `./AppRun`, sans sudo.

277 tests automatisés réussis, dont l’activation d’un fichier de sous-titres dans le vrai mpv,
les formats / archives, la restauration, le décalage, les requêtes des fournisseurs et les changements de contenu.
Les échanges réseau sont vérifiés avec des réponses contrôlées : les services réels, les comptes OpenSubtitles,
le rendu graphique et l’extension Subliminal restent à valider dans un environnement disposant du réseau et d’un bureau graphique.
Le nombre de langues sélectionnables ne garantit pas l’existence d’un sous-titre pour chaque contenu.
